# Hartmann Studios apps (direct download)

Signed Android APKs of Hartmann Studios apps, published here for direct download. Pick an app on the
download page: **https://charleshartmann.com/apps/download/**

Each release holds one app's APK. Paid features unlock inside the app with a secure Stripe checkout tied to your email
(use "Restore purchases" on a new phone). Install: download the `.apk` under *Assets*, open it, and allow your browser
to install apps when Android asks.
